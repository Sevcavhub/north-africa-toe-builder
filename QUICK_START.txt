INTERACTIVE DATACARD BUILDER - QUICK START
========================================================================

WHAT YOU NEED:
1. Python 3.8+ installed (https://www.python.org/downloads/)
2. Flask installed: pip install flask flask-cors

STARTING THE SERVER:
Method 1 (Easiest): Double-click START_DATACARD_BUILDER.bat
Method 2 (Command): python interactive_datacard_server.py

USING THE TOOL:
1. Open browser to http://localhost:5000
2. Search for vehicles (e.g., "Sherman", "Panzer III")
3. Select vehicles with checkboxes
4. (Optional) Override nation for each vehicle
5. Click "Build Datacards"
6. HTML file downloads automatically

STOPPING THE SERVER:
Press Ctrl+C in the terminal window

SHARING WITH A COLLEAGUE:
- Share entire north-africa-toe-builder folder
- They need Python 3.8+ and Flask installed
- Run START_DATACARD_BUILDER.bat or python interactive_datacard_server.py

CLOUD VERSION (NO SETUP NEEDED):
https://sevcavhub.github.io/north-africa-toe-builder/tools.html

TROUBLESHOOTING:
- "Unable to connect": Check server is running in terminal
- "ModuleNotFoundError": Run pip install flask flask-cors
- "Database not found": Ensure database/master_database.db exists

FULL DOCUMENTATION:
See INTERACTIVE_DATACARD_SETUP.md
