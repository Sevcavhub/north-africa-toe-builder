## Changes from v5.1 → v5.2

### Bug Fixes

1. **Weapons Table Not Populating** ✅
   - **Issue**: Script attempted to read non-existent JSON `weapons` column from `bg_reference_vehicles`
   - **Fix**: Updated to read individual columns `weapon_1-4`, `mount_1-4`, `ammo_1-4`
   - **Files Modified**:
     - `generate_book_datacards.py` lines 377-404 (main gun extraction)
     - `generate_book_datacards.py` lines 445-475 (secondary weapons extraction)

2. **Ammo Counts Not Displaying** ✅
   - **Issue**: Template used hardcoded `-` instead of database values
   - **Fix**: Changed template to use `{main_gun_ammo_display}` variable
   - **Data Source**: Raw values from `bg_reference_vehicles.ammo_1-4` (no calculations)
   - **Files Modified**:
     - `generate_book_datacards.py` line 745 (template ammo cell)
     - `generate_book_datacards.py` lines 481-483 (variable scope fix)

## Verified Data Flow

### Ammo Count Pipeline
```
bg_reference_vehicles.ammo_1
    ↓ (SQL query line 380)
ref_row[ammo_col]
    ↓ (assignment line 394)
ammo = ref_row[ammo_col]
    ↓ (assignment line 398)
main_gun_ammo = ammo
    ↓ (display formatting line 483)
main_gun_ammo_display = main_gun_ammo if main_gun_ammo else '-'
    ↓ (template line 745)
<td>{main_gun_ammo_display}</td>
```

**Result**: Database value displayed directly (e.g., Matilda II: `ammo_1 = 9` → displays "9")

### Weapon Extraction Pipeline
```
bg_reference_vehicles: weapon_1-4, mount_1-4
    ↓ (loop lines 387-404)
Find turret-mounted non-MG weapon
    ↓ (assignment lines 397-398)
main_gun = weapon_name
    ↓ (template line 743)
<td>{main_gun}</td>
```

## How to Print Sample

### Option 1: VS Code (Recommended)
1. Open `SAMPLE_DATACARDS_V5.2.md` in VS Code
2. Right-click → "Open Preview" (Ctrl+Shift+V)
3. Print from preview (Ctrl+P)
4. **Print Settings**:
   - Paper: A4 Landscape
   - Margins: 10mm
   - Scale: 100%

### Option 2: Convert to HTML
```bash
# Using Pandoc
pandoc SAMPLE_DATACARDS_V5.2.md -o SAMPLE_DATACARDS_V5.2.html --standalone

# Using Python-Markdown
python -m markdown SAMPLE_DATACARDS_V5.2.md > SAMPLE_DATACARDS_V5.2.html
```

Then open in browser and print (Ctrl+P).

### Option 3: MDBook
```bash
cd books/battleaxe/book
mdbook build
# Open book/index.html → Chapter 2 → Tanks
```

## Known Limitations

### Equipment Without Linkages
Some equipment shows "None" for weapons because they lack `reference_vehicle_id`:
- Stuart I (M3 Light) - `GBR_STUART_I_M3_LIGHT`
- Panzer III Command variants
- Light Tank Mk6 (reconnaissance, may be correct)
- L3/35 Tankette (may only have MG)

**Status**: Part of ongoing Phase 9B equipment linkage work (currently 20% → target 100%)

### MG-Only Vehicles
Vehicles with only machine guns may correctly show "None" for main gun:
- Scout cars
- Armored cars (some variants)
- Tankettes
