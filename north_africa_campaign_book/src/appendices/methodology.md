# Methodology

## Data Collection

All data in this reference work was extracted from Tier 1 and Tier 2 primary sources:

### Tier 1 Sources
- Official military histories (British, German, Italian, American official series)
- War diaries and unit records (National Archives, Bundesarchiv)
- Contemporary military manuals and technical documentation
- Memoirs by senior commanders with archival verification

### Tier 2 Sources
- Peer-reviewed academic journals
- Museum archives and collections
- Cross-referenced secondary sources with primary documentation

### Excluded Sources
- Wikipedia and general encyclopedias
- Unverified web content
- Sources without primary documentation

## Data Quality Standards

Each unit chapter includes:
- **Confidence rating**: 75-95% based on source quality
- **Source citations**: Complete bibliography with archive references
- **Known gaps**: Documented limitations and missing data
- **Cross-references**: Multiple independent source verification

## Schema Compliance

All data follows unified TO&E schema v3.0.0:
- Personnel (officers, NCOs, enlisted)
- Equipment (vehicles, artillery, aircraft)
- Supply and logistics (fuel, ammunition, water, operational radius)
- Environmental conditions (weather, terrain, seasonal impacts)

## Validation Process

1. Extract data from primary sources
2. Cross-reference with independent sources
3. Validate against known historical outcomes
4. Calculate derived values from standard establishments
5. Document gaps and uncertainties

---
*All data validated to 75%+ confidence using Tier 1/2 sources only*
