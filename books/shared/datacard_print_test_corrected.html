Print Instructions

CORRECTED DIMENSIONS: 84mm (width) × 48mm (height)

  1. Open Print Dialog (Ctrl+P or Cmd+P)
  2. Set Layout: Landscape
  3. Set Paper: A4 (210mm × 297mm)
  4. Set Scale: 100% (Do not shrink to fit)
  5. Enable: Background graphics
  6. Disable: Headers and footers
  7. Preview: Should see 9 cards in 3×3 grid
  8. Print or Save as PDF

Expected output: 9 cards per page, each 84mm × 48mm with 1mm white border

Grid size: 256mm × 148mm centered on A4 landscape page
