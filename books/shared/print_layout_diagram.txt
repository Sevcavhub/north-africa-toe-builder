GRID SPACING CALCULATION
═════════════════════════════════════════

Horizontal (4 cards):
  (48mm × 4) + (2mm × 3 gaps) = 192mm + 6mm = 198mm

Vertical (2 rows):
  (84mm × 2) + (2mm × 1 gap)  = 168mm + 2mm = 170mm

Page centering:
  Horizontal margins: (297mm - 198mm) / 2 = 49.5mm per side
  Vertical margins:   (210mm - 170mm) / 2 = 20mm per side

Total page usage:
  Grid: 198mm × 170mm
  Page: 297mm × 210mm
  Efficiency: 66.7% × 81.0% = 54% (good utilization)

PRINTING REFERENCE
══════════════════════════════════════════

Critical Settings:
  • Page size: A4 (210mm × 297mm)
  • Orientation: LANDSCAPE (critical!)
  • Scale: 100% (do not adjust)
  • Margins: Top/Bottom 20mm, Left/Right 49.5mm
  • Background graphics: ON (for colors)
  • Headers/footers: OFF

Quality Checks After Printing:
  1. Measure card: Should be 48mm × 84mm (±0.5mm)
  2. Count cards: Should be exactly 8 per page
  3. Check gaps: Should be ~2mm between cards
  4. Verify border: 1mm white border visible
  5. Text readable: All text clear at printed size
  6. Colors correct: Nation themes display properly

CUTTING GUIDE
═════════════════════════════════════════

For Physical Cards:
  1. Print on 200-300gsm cardstock
  2. Use rotary cutter or guillotine for straight edges
  3. Cut columns first (4 vertical cuts)
  4. Then cut rows (3 horizontal cuts per column)
  5. Result: 8 cards per sheet, 48mm × 84mm each

Batch Cutting:
  • Stack 5-10 sheets
  • Align edges carefully
  • Cut all sheets at once for consistency
  • Cards should be identical size
