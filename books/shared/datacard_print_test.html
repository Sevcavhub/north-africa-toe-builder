Print Instructions

  1. Open Print Dialog (Ctrl+P or Cmd+P)
  2. Set Layout: Landscape
  3. Set Paper: A4 (210mm × 297mm)
  4. Set Scale: 100% (Do not shrink to fit)
  5. Enable: Background graphics
  6. Disable: Headers and footers
  7. Preview: Should see 8 cards in 4×2 grid
  8. Print or Save as PDF

Expected output: 8 cards per page, each 48mm × 84mm with 1mm white border
